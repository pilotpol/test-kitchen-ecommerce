# ชุดประเมิน AI ของ test-app-

โฟลเดอร์นี้เก็บกรณีประเมินพฤติกรรม AI ของแอป ใช้กับ Evals และ Simulation ของ PromptServe และใช้เป็นหลักฐานก่อน Go live

## รูปแบบไฟล์
หนึ่งไฟล์ต่อกลุ่มพฤติกรรม ชื่อ `<กลุ่ม>.jsonl` หนึ่งบรรทัดต่อกรณี

```json
{"id": "faq-001", "input": "คำถามของผู้ใช้", "expect": "พฤติกรรมที่คาดหวัง เช่น ตอบพร้อมอ้างเอกสาร", "judge": "rule|llm", "criteria": ["อ้างชื่อเอกสาร", "ไม่เดาข้อมูล"], "acceptance": "AC-03"}
```

## กติกา
- อย่างน้อย 10 กรณีต่อแอป ครอบคลุมกรณีปกติ กรณีขอบ และกรณีที่ต้องปฏิเสธหรือส่งต่อเจ้าหน้าที่
- ทุกกรณีอ้างเกณฑ์ยอมรับใน Spec
- ห้ามใช้ข้อมูลส่วนบุคคลจริง
- เกณฑ์ตัดสินเป็นพฤติกรรม ไม่ใช่ข้อความตรงตัว
