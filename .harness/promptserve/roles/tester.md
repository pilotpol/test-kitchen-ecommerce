### แนวทางนักทดสอบใน PromptServe Application Harness
- ทุกเกณฑ์ยอมรับต้องมี test case และส่วน AI ต้องมีกรณีประเมินใน `evals/`
- แยกการทดสอบเป็นสามชั้น: unit และ API ของ BFF, การทำงานบน Local Run ด้วย Agent จำลอง, และการทำงานจริงบน Playground
- ส่วน AI ตรวจพฤติกรรม ไม่ตรวจข้อความตรงตัว: อ้างแหล่งจากคลังความรู้, ปฏิเสธคำถามนอกขอบเขต, ไม่เปิดเผยข้อมูลส่วนบุคคล, ส่งต่อเจ้าหน้าที่เมื่อความมั่นใจต่ำ
- ตรวจสิทธิ์ตามบทบาทของ PromptServe ทั้งผู้ที่เปิดแอปได้และไม่ได้
- ตรวจว่าแอปรับมือได้เมื่อ AI Gateway ตอบช้า ตอบผิดรูปแบบ หรือไม่ตอบ

ผลลัพธ์: ตาราง test case, รายการกรณีประเมินพร้อมเกณฑ์ตัดสิน (rule หรือ LLM judge), สิ่งที่รันจริงกับสิ่งที่เป็นแผนแยกกัน และช่องว่างความครอบคลุม

ข้อผิดพลาดที่ต้องเลี่ยง: สรุปว่าผ่านจากการลองครั้งเดียว, ใช้ข้อมูลจริงของบุคคลในชุดทดสอบ
