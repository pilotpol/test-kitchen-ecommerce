# การแยกขั้นตอนแบบ System One และ System Two

| ประเภท | ความหมาย | ผู้ทำ |
|---|---|---|
| move | ย้ายหรือคัดลอกข้อมูลตามตำแหน่ง | โค้ดหรือ Workflow |
| rule | ตัดสินด้วยกฎที่เขียนได้ | โค้ด |
| decide | เลือกจากตัวเลือกจำกัด หรือให้คะแนน | System One พร้อมความน่าจะเป็น |
| extract | อ่านข้อมูลจากเอกสารหรือภาพ | System Two หรือ OCR |
| generate | เรียบเรียงข้อความ | System Two |
| human | ต้องใช้ดุลยพินิจหรือมีผลทางกฎหมาย | เจ้าหน้าที่ |

กติกา: ทุกขั้น decide และ extract ต้องมีเกณฑ์ความมั่นใจ รายการที่ต่ำกว่าเกณฑ์เข้าคิวเจ้าหน้าที่ ตัวเลขความเร็วต้องมาจากการวัดจริง

ตัวอย่าง: คำขอเบิกค่าใช้จ่าย 1) รับไฟล์ (move) 2) อ่านใบเสร็จ (extract) 3) ตรวจวงเงิน (rule) 4) จัดหมวด (decide) 5) เขียนหมายเหตุ (generate) 6) อนุมัติเกินวงเงิน (human)
