# ข้อผิดพลาดที่พบบ่อย

- ใช้โมเดลกับงานที่เป็นกฎ ทำให้ช้า แพง และผลไม่คงที่
- เขียน system prompt ยาวในโค้ดของแอปแทนการตั้งค่า Agent บนแพลตฟอร์ม
- ทดสอบ AI ด้วยการเทียบข้อความตรงตัว
- ไม่มีทางส่งต่อเจ้าหน้าที่ ทำให้ผู้ใช้ติดอยู่กับคำตอบที่ผิด
- เก็บข้อมูลส่วนบุคคลเกินจำเป็น หรือบันทึกลง log
- แก้ `packages/` ของแพลตฟอร์มเพื่อให้งานผ่าน
