- ห้ามถามเรื่อง tech stack: หน้าเว็บ Next.js, backend Go + Gin, ฐานข้อมูล PostgreSQL, Agent และคลังความรู้ของ PromptServe เป็นมาตรฐานที่ใช้เสมอ ให้ถามเฉพาะความต้องการทางธุรกิจ ข้อมูลที่ต้องเก็บ หน้าจอ และพฤติกรรมของ AI
- งานใดในกระบวนการเป็นงานตายตัว (ย้ายข้อมูล ตรวจตามกฎ) งานใดต้องตัดสินใจ งานใดต้องอ่านเอกสารหรือเรียบเรียงข้อความ และจุดใดต้องให้เจ้าหน้าที่ยืนยัน เพื่อแบ่งงานให้ Workflow, Agent และคนได้ถูก
- Agent ของแอปต้องค้นคลังความรู้ใด และคำตอบต้องอ้างแหล่งหรือไม่
- ตัวอย่างคำถามจริงและคำตอบที่ถูกต้องอย่างน้อย 5 ข้อ สำหรับชุดประเมิน AI ใน evals/
- บทบาทผู้ใช้ใน PromptServe ที่เปิดแอปได้ และข้อมูลส่วนบุคคลที่แอปแตะ
- ถ้างานนี้อยู่ในขั้นทำข้อเสนอ (presales): ผู้ตัดสินใจและเกณฑ์การให้คะแนนของลูกค้า, กำหนดส่งข้อเสนอ, คู่แข่งที่ทราบ, ตัวเลขธุรกิจของลูกค้าที่มีแหล่งอ้างอิง, reference ที่ใช้ชื่อลูกค้าได้ และ TOR ให้ใส่ราคาใน deck หรือแยกซอง
