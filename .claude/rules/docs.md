# เอกสารของโครงการ

- การตัดสินใจที่มีทางเลือกจริงบันทึกเป็น ADR ใหม่ใน `docs/adr/` จาก `0000-template.md` เลขต่อจากฉบับล่าสุด ห้ามแก้ ADR ที่ตัดสินแล้ว ให้เขียนฉบับใหม่ที่แทนที่
- `docs/runbook.md` อัปเดตทุกครั้งที่เปลี่ยนวิธีติดตั้ง ค่าตั้ง หรือการดูแลระบบ
- เอกสารที่ลูกค้าอาจเห็นใช้ภาษาไทยทางการ ห้ามใช้เครื่องหมาย § และ em-dash
