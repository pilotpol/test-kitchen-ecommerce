# คลังความรู้ของ test-app-

วางเอกสารที่ Agent ของแอปต้องใช้ตอบไว้ในโฟลเดอร์นี้ เป็นไฟล์ `.md`, `.txt`, `.csv` หรือ `.json`
เมื่อส่งแอปขึ้น PromptServe แพลตฟอร์มสร้างคลังความรู้ชื่อ `app-<slug>` ให้เอง นำเอกสารทุกไฟล์เข้าคลัง
และผูกกับ Agent ของแอปโดยอัตโนมัติ ส่งแอปขึ้นครั้งถัดไป เอกสารที่แก้จะถูกนำเข้าใหม่

ไฟล์นี้ (README.md) ไม่ถูกนำเข้าคลัง
ห้ามใส่ข้อมูลส่วนบุคคลหรือค่าลับในเอกสารของคลังความรู้
