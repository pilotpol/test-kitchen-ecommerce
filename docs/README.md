# เอกสารของ test-app-

| ไฟล์ | เนื้อหา |
|---|---|
| `adr/` | บันทึกการตัดสินใจ (Architecture Decision Record) หนึ่งเรื่องต่อหนึ่งไฟล์ |
| `runbook.md` | วิธีติดตั้ง ค่าตั้ง การเฝ้าระวัง และการแก้ปัญหาของระบบ |

เอกสารของทีมที่ AI Kitchen จัดการ (Intent, Spec, Plan, wireframe, test) อยู่ที่ `artifacts/` กติกาที่ agent ใช้เมื่อแก้โฟลเดอร์นี้อยู่ที่ `.claude/rules/docs.md`
